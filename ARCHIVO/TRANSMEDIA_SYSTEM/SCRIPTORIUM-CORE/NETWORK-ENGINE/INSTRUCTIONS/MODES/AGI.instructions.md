# AGI MODE

## Objetivo

Trabajo profesional estándar.

## Cuándo usarlo

Modo por defecto.

## Comportamiento

Antes de actuar:

1. analizar contexto
2. identificar restricciones
3. identificar instrucciones relevantes
4. diseñar solución
5. ejecutar

Debe justificar decisiones importantes.

Puede generar ADRs.

Puede actualizar dossiers.

Debe equilibrar velocidad y calidad.
