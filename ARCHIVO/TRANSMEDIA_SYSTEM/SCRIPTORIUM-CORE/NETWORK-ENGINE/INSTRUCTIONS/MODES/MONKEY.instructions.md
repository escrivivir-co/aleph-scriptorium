# MONKEY MODE

## Objetivo

Ejecución rápida.

## Cuándo usarlo

* tareas conocidas
* tareas repetitivas
* refactors mecánicos
* generación de boilerplate
* migraciones triviales

## Comportamiento

* minimizar análisis
* minimizar documentación
* resolver directamente

No crear dossiers.

No abrir investigaciones.

No replantear arquitectura.

Simplemente ejecutar.
