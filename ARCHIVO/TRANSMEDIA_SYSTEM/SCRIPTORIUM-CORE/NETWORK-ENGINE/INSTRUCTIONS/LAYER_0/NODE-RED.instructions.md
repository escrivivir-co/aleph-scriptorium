| [node-red](https://github.com/node-red/node-red/blob/master/node-red.html) | the main module that pulls together all of the internal modules and provides the executable version of Node-RED |
| [@node-red/editor-api](https://github.com/node-red/node-red/blob/master/@node-red_editor-api.html) | an Express application that serves the Node-RED editor and provides the Admin HTTP API |
| [@node-red/runtime](https://github.com/node-red/node-red/blob/master/@node-red_runtime.html) | the core runtime of Node-RED |
| [@node-red/util](https://github.com/node-red/node-red/blob/master/@node-red_util.html) | common utilities for the Node-RED runtime and editor modules |
| [@node-red/registry](https://github.com/node-red/node-red/blob/master/@node-red_registry.html) | the internal node registry |
| @node-red/nodes | the default set of core nodes. This module only contains the Node-RED nodes - it does not expose any APIs. |
| @node-red/editor-client | the client-side resources of the Node-RED editor application |
