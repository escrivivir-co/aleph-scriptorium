## §3 — HiperIPL desde la lente GREEN

### 3.1 Las dos preguntas Gaia (refactor)

EXTERNO preguntaba: *¿acopla o desacopla?* Traducción operativa:

1. **¿Mejora la eficiencia exergética de la coordinación?** (coste material vs beneficio de voz persistente)
2. **¿Produce anestesia?** (firmar sustituye bloquear la maquinaria, secar el acuífero)

### 3.2 Anestésico vs sensor

| Modo | Comportamiento | Riesgo |
|---|---|---|
| **Anestésico** | UI celebra firmas; conflicto físico continúa | Hipótesis C |
| **Sensor** | Registra advertencias tempranas; memoria ecológica | Aspiración EXTERNO §3.A |
| **Derivador** | Señal urgente → UI dice "no votes: actúa" | futures-engine + Marcuse |

Comportamiento **derivador** no implementado — SPEC?-023.

### 3.3 Oráculo de límites planetarios (propuesta)

Inspiración: límites de Amsterdam / datos abiertos / sensores territorio.

| Capa | Función |
|---|---|
| Input | API clima/agua/biodiversidad (candidatas: no listadas) |
| Horn rule | `si limite_rojo → Next(vote) = false` |
| UI | Nodo azul muestra bandera; iniciativa no admite cuórum |
| Override | **Ninguno** por diseño aspiracional — SPEC?-024 (¿excepción?) |

### 3.4 Huella L2

Opciones documentadas, no medidas:

- Anclaje batch (rollup) vs registro continuo.
- IPFS/Oasis off-chain + hash on-chain (menor huella).
- Compensación / no compensación (greenwashing) — SPEC?-025.

### 3.5 Vía roja vs vía negra (EXTERNO) bajo GREEN

| Vía | Punto ciego eco (EXTERNO) | Corrección candidata |
|---|---|---|
| Roja (planificación) | Ignora señales débiles | Oráculo en capa garantías |
| Negra (comuna) | Puede agotar acuífero por consenso | Límite duro + derivación |
